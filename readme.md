## Requirements

- Go 1.24.8 or higher
- git

## Installation

Linux:

```sh
git clone https://github.com/rillmind/numberGuessingGameCli.git
cd numberGuessingGameCli
go build -o numberGuessing ./cmd
sudo cp numberGuessing /usr/bin/
```

Windows: 

```sh
git clone https://github.com/rillmind/taskManagerCli.git
cd numberGuessingGameCli
go build -o numberGuessing .\cmd\
```
